# Análise de Variação de Preços - Cesta Básica 🛒

## 📖 Sobre o Projeto
Este projeto foi desenvolvido como parte de uma atividade acadêmica de Lógica de Programação. O sistema automatiza a análise de preços de produtos da cesta básica, comparando o valor atual com o do mês anterior. 

A partir desses dados, o programa calcula a variação percentual matemática e emite um diagnóstico automático e preciso (**AUMENTO**, **QUEDA** ou **ESTÁVEL**), auxiliando na tomada de decisão e na identificação de cenários de preços abusivos, conforme diretrizes de órgãos de defesa do consumidor.

## 🚀 Funcionalidades
- Coleta interativa de dados (nome, preço anterior e preço atual) para múltiplos produtos.
- Cálculo automático da variação percentual utilizando operadores matemáticos.
- Estrutura de decisão (`if/else`) baseada na porcentagem descoberta.
- Geração de um relatório final no terminal, formatado e alinhado para fácil leitura por tomadores de decisão.

## 🛠️ Tecnologias e Ferramentas
- **Linguagem C**: Para a construção do sistema executável e de alto desempenho.
- **Pseudocódigo (Portugol)**: Para a prototipação e documentação da lógica estruturada.
- **OnlineGDB**: Utilizado como ambiente de desenvolvimento e compilação em nuvem.

## ⚙️ Como Executar o Projeto

**Opção 1: Via Navegador (Mais rápido)**
1. Acesse o compilador [OnlineGDB](https://www.onlinegdb.com/online_c_compiler).
2. Selecione a linguagem `C` no canto superior direito.
3. Cole o código do arquivo `main.c` na área de texto.
4. Clique no botão **Run** e interaja com o terminal (use ponto `.` para casas decimais).

**Opção 2: Localmente (Requer GCC)**
1. Clone este repositório para a sua máquina.
2. Abra o terminal na pasta do projeto.
3. Compile o código com o comando: `gcc main.c -o cesta_basica`
4. Execute o programa: `./cesta_basica` (Linux/Mac) ou `cesta_basica.exe` (Windows).
